## Snorlu AI Culling – bản thử nghiệm (beta)

Ứng dụng lọc ảnh cosplay / đường phố, chạy **hoàn toàn offline** trên Windows 10/11.
Không cần cài Git, Python hay card đồ hoạ — mọi thứ đã nằm trong bộ cài.

### Tải file nào?
- **`Snorlu-AI-Culling-…-BoCai.zip`** ← tải file này (bộ cài + hướng dẫn tiếng Việt).
- `Snorlu-AI-Culling-…-portable.zip`: bản không cần cài, giải nén ra là chạy `Snorlu.exe`.
- `Snorlu-AI-Culling-Setup-….exe`: chỉ riêng bộ cài.

### Cài trong 3 bước
1. Nhấp phải vào file `…-BoCai.zip` → **Extract All** (Giải nén tất cả).
2. Nhấp đúp `Snorlu-AI-Culling-Setup-….exe`. Nếu Windows báo *“Windows protected your PC”*:
   bấm **More info** → **Run anyway** (bộ cài chưa có chữ ký số trả phí, không phải virus).
3. Next → Install → Finish. Mở ứng dụng bằng biểu tượng **Snorlu AI Culling**.

Hướng dẫn chi tiết: file `HUONG_DAN_CAI_DAT.txt` trong file zip.

Ảnh gốc không bao giờ bị sửa, xoá hay di chuyển; “Xuất ảnh” chỉ sao chép.
