HƯỚNG DẪN CÀI ĐẶT KIRAPICK 3.0.0
=========================================================

KHÔNG cần cài Git, Python hay gì khác. Máy cần Windows 10/11 64-bit, khoảng 3 GB ổ trống
(bản CUDA: khoảng 6 GB). Có card đồ hoạ thì AI chạy nhanh hơn, không có vẫn chạy được.

CHỌN BẢN NÀO?
  - KiraPick 3.0.0 (bản chính thức, DirectML): cho mọi máy. Tải KiraPick-3.0.0-BoCai.zip
      (bên trong: KiraPick-Setup-3.0.0.exe + file .bin + owner_backup.ps1 + file này).
  - KiraPick 3.0.0a - NVIDIA CUDA: cho máy có card NVIDIA (GTX 10xx trở lên, driver mới).
      Không có file .zip: tải TẤT CẢ KiraPick-Setup-3.0.0a.exe, mọi file KiraPick-Setup-3.0.0a-*.bin,
      owner_backup.ps1 và file này vào CÙNG MỘT thư mục.
  Bản 3.0 THAY bản 2.2.x đang có trên máy (cùng một ứng dụng).

CÁCH DÁN LỆNH: bấm Start, gõ PowerShell, Enter. Chép lệnh (Ctrl+C), bấm vào cửa sổ PowerShell,
nhấp chuột phải để dán, rồi Enter. Máy không có ổ D: thì thay D: bằng C: trong mọi lệnh.

-----------------------------------------------------------------
BƯỚC 1 - ĐẶT FILE VÀO MỘT THƯ MỤC
-----------------------------------------------------------------
  - Bản DirectML: nhấp phải file .zip -> "Extract All..." -> gõ D:\KiraPick-3.0 -> "Extract".
  - Bản CUDA: chép tất cả các file đã tải vào thư mục D:\KiraPick-3.0

-----------------------------------------------------------------
BƯỚC 2 - SAO LƯU (rất nên làm nếu đang dùng KiraPick 2.2)
-----------------------------------------------------------------
Mở một buổi chụp cũ bằng bản 3.0 sẽ nâng cấp dữ liệu của buổi đó; sau đó KiraPick 2.2 không mở lại
được buổi đó nữa. Sao lưu để có thể quay lại.
1. Đóng MỌI cửa sổ KiraPick.
2. Dán vào PowerShell:
     powershell -ExecutionPolicy Bypass -File D:\KiraPick-3.0\owner_backup.ps1 -Destination D:\KiraPick-SaoLuu
3. Cuối cùng phải có dòng MÀU XANH "... kiểm tra SHA-256: khớp". Chụp màn hình dòng
   "Bản sao lưu nằm ở: D:\KiraPick-SaoLuu\..." để nhớ đường dẫn.
   Script chỉ chép dữ liệu KiraPick (không chép ảnh) và không bao giờ ghi đè bản sao lưu cũ.

-----------------------------------------------------------------
BƯỚC 3 - CÀI ĐẶT
-----------------------------------------------------------------
1. Mở D:\KiraPick-3.0, nhấp đúp KiraPick-Setup-3.0.0.exe (bản CUDA: KiraPick-Setup-3.0.0a.exe).
   File .bin PHẢI nằm cạnh file .exe.
2. Nếu hiện khung xanh "Windows protected your PC": bộ cài chưa có chữ ký số, KHÔNG phải virus.
   Bấm "More info" -> "Run anyway" (màn hình phải ghi "Unknown publisher").
   DỪNG LẠI nếu Windows Defender báo virus.
3. "I accept the agreement" -> Next -> Next -> Install -> Finish. Không cần quyền Administrator.
   Nếu bộ cài hỏi "insert disk" / không thấy file .bin: file .bin chưa nằm cạnh file .exe.
Mở app bằng biểu tượng "KiraPick" ngoài màn hình hoặc trong menu Start.

-----------------------------------------------------------------
BƯỚC 4 - DÙNG (4 nút trên thanh công cụ, làm lần lượt)
-----------------------------------------------------------------
1. 📂 Nhập ảnh          -> chọn thư mục ảnh của một buổi chụp (RAW hoặc JPEG).
2. 🧠 Nhận diện chủ thể -> AI gom ảnh theo từng trang phục / người. Một nhóm bị tách đôi:
                          tick 2 ô của chúng rồi bấm "🔗 Gộp". Gộp nhầm: Ctrl+Z.
3. 📊 Phân tích ảnh      -> AI chấm điểm (nét, mặt, sáng, bố cục, thẩm mỹ).
4. ⭐ Chọn ảnh           -> nhập số ảnh muốn chọn cho mỗi chủ thể.
Xem lại: P = giữ, X = loại, số 1-5 = sao, F = yêu thích; bấm nhầm thì Ctrl+Z.
Cuối cùng: "⤴ Xuất ảnh" -> chọn ảnh, định dạng (RAW + JPEG, chỉ RAW, chỉ JPEG), thư mục đích -> Sao chép.
  Mặc định thư mục đích CHỈ có ảnh; tick "Xuất kèm danh sách ảnh đã chọn" nếu muốn có thêm
  thư mục con _kirapick_danh_sach (danh sách CSV/JSON).
Mẹo: Space = xem ảnh lớn, Esc = về lưới, E = phóng tới mắt, Z = phóng to. Phím tắt đầy đủ: F1.

-----------------------------------------------------------------
YÊN TÂM VỀ ẢNH CỦA BẠN
-----------------------------------------------------------------
- KiraPick KHÔNG BAO GIỜ sửa, xoá, đổi tên hay di chuyển ảnh gốc. "Xuất ảnh" chỉ SAO CHÉP.
- KiraPick chạy offline, không gửi ảnh hay dữ liệu đi đâu (chỉ nút "Cập nhật KiraPick" dùng mạng, khi bạn bấm).

-----------------------------------------------------------------
QUAY LẠI KIRAPICK 2.2 (chỉ khi cần)
-----------------------------------------------------------------
1. Gỡ 3.0: Start -> "Gỡ cài đặt KiraPick" (hoặc Settings -> Apps -> KiraPick -> Uninstall).
2. Cài lại bản 2.2.1 (hoặc 2.2.0a cho CUDA) từ trang phát hành KiraPick trên GitHub.
3. Đóng mọi KiraPick, xem tên bản sao lưu:
     Get-ChildItem D:\KiraPick-SaoLuu -Directory | Select-Object Name
   rồi dán lệnh dưới, thay TEN_BAN_SAO_LUU bằng tên bản sao lưu của Bước 2 (ví dụ 20261105-153000):
     powershell -ExecutionPolicy Bypass -File D:\KiraPick-3.0\owner_backup.ps1 -Restore D:\KiraPick-SaoLuu\TEN_BAN_SAO_LUU
   Phải thấy dòng xanh "Đã khôi phục ... SHA-256: khớp". Script không xoá gì: dữ liệu hiện tại được cất
   sang thư mục KiraPick.truoc-khoi-phuc-<ngày-giờ>.
Ảnh gốc và ảnh đã xuất không bị ảnh hưởng.

-----------------------------------------------------------------
KHI GẶP LỖI
-----------------------------------------------------------------
Chụp màn hình lỗi và gửi cho người đã chia sẻ ứng dụng cho bạn, kèm thư mục log:
  bấm Windows + R, dán %LOCALAPPDATA%\KiraPick\logs rồi Enter, gửi các file trong thư mục mở ra.
