# KiraPick 2.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Technical + personal-taste scores (CLIP ViT-L/14, LAION, TOPIQ NR/face), clearer UI, signed AI-model updates, three editions (2.2.0 DirectML, 2.2.0a CUDA, 2.2.0b OpenVINO).

**Architecture:** New ONNX models run in the existing quality stage (stage v5) and store values in `measurements.values_json` plus per-photo CLIP vectors in a new `asset_vectors` table. A numpy taste model trains from the global learning store (v6). Ranking = blend of the technical score and the taste score. A separate `app/updates/` package is the only code allowed to use the network.

**Tech Stack:** Python 3.12, PySide6, SQLite, ONNX Runtime (DirectML / CUDA / OpenVINO builds), numpy, `cryptography` (Ed25519), PyTorch only in build-time converters.

**Spec:** `docs/superpowers/specs/2026-10-28-kirapick-2.2-design.md`

## Global Constraints

- Originals are never modified; exports are copies.
- No faked outputs: a missing model or insufficient data means "chưa chấm" with the reason.
- Analysis and normal use never open network connections. Only `app/updates/` may do so, on a user click or on the opt-in daily check (default **off**).
- CPU fallback always works; one heavy model at a time.
- Taste gate: ≥ 60 used decisions, ≥ 20 positive and ≥ 20 negative, 5-fold CV (folds grouped by shoot day), weighted AUC ≥ 0.65.
- Label weights: ★4–5 or ❤ = +1.5; ✓ or ★3 = +1; ✗ or ★1 = −1 (weight 1); client pick = +0.3; pair answer = ±0.5; ★2 or undecided = not used.
- Ranking: `(1 − w)·tech + w·taste` with w = 0.5 (⚙ setting). Use w = 0 when taste is not ready.
  - Hard defect (eyes closed, or focus part < 30) caps the ranking at `tech`.
  - Exception: an artistic tag is present **and** taste ≥ 70.
- CLIP preprocessing: shorter side → 224 bicubic, centre crop 224, mean (0.48145466, 0.4578275, 0.40821073), std (0.26862954, 0.26130258, 0.27577711). The embedding is L2-normalised.
- Versions: `2.2.0` (DirectML, official), `2.2.0a` (CUDA, pre-release), `2.2.0b` (OpenVINO, pre-release).
- UI text is in Vietnamese. Tests use pytest; GUI tests run offscreen.

## Review Focus

1. The same photo is re-decided many times (✓ → ✗ → ★5). Expect one learning row, holding the last decision.
2. A learning store written by 2.1 (v5) is opened by 2.2. Expect migration with no data lost and old rows used for tech-only features. Rows without CLIP do not count toward the CLIP gate.
3. A photo with no person, or no face. Expect CLIP/LAION/TOPIQ-NR to still score the photo, and face IQA to show "chưa chấm – không thấy mặt".
4. An update is interrupted, the PC is offline, or the catalogue is tampered with. Expect: the active models are unchanged, the app works, and a clear message is shown.
5. The CLIP model is missing (the build skipped it, or the file is corrupt). Expect the aesthetic part to use TOPIQ only, taste to say "chưa có mô hình CLIP", and no crash.

### Task 1: Taste model core
**Files:**
- Create: `app/learning/taste.py`
- Test: `tests/unit/test_taste.py`

**Interfaces:**
- Produces: `@dataclass TasteExample(label: int, weight: float, day: str, clip: np.ndarray | None, parts: dict[str, float | None])`
- Produces: `@dataclass TasteModel(w: np.ndarray, b: float, mean: np.ndarray, std: np.ndarray, n: int, n_pos: int, n_neg: int, auc: float, version: str)` with:
  - `predict(clip, parts) -> float` (0..100)
  - `concepts(prompts: dict[str, np.ndarray], k=3) -> list[tuple[str, float]]`

- Produces: `@dataclass TasteStatus(ready: bool, reason: str, model: TasteModel | None)`
- Produces: `train(examples: list[TasteExample]) -> TasteStatus`
- Features: CLIP (768), then standardised `PARTS = ("focus","eyes","face","exposure","framing","aesthetic")`, each with a missing flag (missing value → 0 after standardising).
- Training: weighted logistic regression, L2 λ = 1.0, 300 Newton/IRLS iterations max.

- [ ] Write the failing tests:

  - `test_random_labels_keep_the_gate_closed`: assert `not ready` and "độ khớp" in reason.
  - `test_too_few_examples`: 30 examples; assert the reason starts with "Chưa đủ dữ liệu: 30/60".
  - `test_folds_are_grouped_by_day`: 3 days → no crash.
  - `test_weights_change_the_fit`: weight=0 rows are ignored.
  - `test_missing_clip_rows_are_skipped`: `clip=None` rows are not counted.
- [ ] Run `pytest tests/unit/test_taste.py -q` → FAIL (module missing).
